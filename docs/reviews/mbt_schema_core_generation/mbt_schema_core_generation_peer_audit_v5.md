```text
crates/codegen/src/rust_emit.rs
```

```text

  VALID_*_MASK emits the OR of dictionary bit constants without leading `0 |`

  key-order validation emits a clippy-clean single condition without changing
  the tuple comparison or InvalidTimeGrid error

  use `{rows}` field-init shorthand only when the payload repeated field name
  is exactly `rows`; otherwise keep explicit `{field_name}: rows`
```

## Specific Checks

### Narrowness

The amendment is narrow enough because it binds three generated Rust shape
changes and no descriptor, schema model, option, runtime, envelope, adapter,
dependency, checksum algorithm, schema hash, validation, or trusted-access
change.

### Semantics

The expected runtime semantics are unchanged:

- a valid bitmask remains the bitwise OR of all declared dictionary bits;
- key-order validation still compares the generated current key tuple against
  the previous key tuple;
- key-order failure still returns
  `TransportError::InvalidTimeGrid("key order regression".to_string())`;
- payload construction still consumes the same owned row vector after
  `validate_rows(&rows)?`;
- payload schema version remains `SCHEMA_VERSION_VALUE`.
